# 更新记录

[English](../../CHANGELOG.md) · **简体中文** · [繁體中文](../zh-TW/CHANGELOG.md)

记录对玩家和贡献者有影响的变化。版本号与桌面 App 一致。

## 0.2.5 — 待发布

- 模组目录搜索框左侧新增「操作」菜单，提供「一键安装」「一键更新」「一键卸载」。每张卡片都有常驻勾选框，按模组 ID 记录选中状态：先勾选卡片，再选择操作。菜单右侧数量按「已勾选 ∩ 符合该操作条件」实时计算；未勾选任何卡片时给出友好提示，不会执行任何模组；不符合条件的已勾选卡片会被过滤并提示，绝不会误操作未勾选的卡片。
- 执行前弹出确认对话框，列出本次实际处理的模组（卸载使用更强的确认措辞），并说明被过滤掉的模组数量。执行仍按目录顺序串行复用现有下载、校验、安装/更新/卸载命令，每次写入前重新核对资格并确认游戏已关闭，失败后重扫且单项失败不中断后续；进度对话框逐项显示状态并汇总成功 / 失败 / 跳过数量。成功的模组自动取消勾选，失败与跳过的保留勾选便于重试。
- 修复「操作」菜单鼠标从按钮移入菜单时提前消失的问题：按钮与菜单组成完整交互区域，透明桥接覆盖间隙，悬停与点击协同；只有离开整个区域、点击外部、按 Esc 或选择某项操作才关闭。搜索框宽度约翻倍，并与「操作」按钮在紧凑的 Flex 行中水平对齐，窄窗口下自适应。

## 0.2.4 — 2026-11-21

- 将模组卡片封面从桌面端内置前端资源迁至可选的 Cloudflare R2 图床并经目录 Worker 分发（[ADR-016](architecture/ADR-016-r2-mod-covers.md)），减小约 5.8 MB 安装包体积，后续新增模组或更换封面无需重装客户端。
- 同步收录 **尖刺圆环（Spike Ring `v0.1.0`）** 以及 **泡泡爆破（`v0.1.2`）**、**滚筒嘉年华（`v0.1.8`）**、**独立高清（`v0.1.2`）**、**玩家聚光灯（`v0.1.1`）** 的运行流畅度优化版本。

## 0.2.3 — 2026-11-20

- 新增第一方 3D 派对小游戏 **泡泡爆破（Bubble Blitz `v0.1.0`）**：每人 3 滴血（最后 1 血归零进入 4 秒重伤濒死可被撞击处决，或由救命针自动自救），4 套随机工业地图含传送带，复用原版角色、爆炸粒子与 3D 工业道具，并配有底部仅自己可见的 CRT 属性状态栏。
- 新增**多小游戏共存注册中心**（[ADR-015](architecture/ADR-015-multi-minigame-hub.md)），同步将 **滚筒嘉年华（Roller Carnival）** 升级至 `v0.1.6`，现可与泡泡爆破及后续更多自研小游戏同时安装并在默认、自定义歌单、街机、本地同屏与过场 15 格 CRT 抽签池中共存。

## 0.2.2 — 2026-11-20

- 内置模组加载器升级至 v5，支持识别启动阶段延后挂载的常驻 HUD（如 MachineParty+ 右上角语音按钮），稳定排开大厅重叠的模组按钮且不影响原版按钮。
- 设置页新增内置加载器版本显示与“重载加载器”按钮；应用更新包含新版加载器时，会在游戏关闭后自动完成加载器升级，无需重装模组。

## 0.2.1 — 2026-11-20

- 内置模组加载器升级至 v4，自动排开大厅中互相重叠的模组按钮（例如 MachineParty+ 与房间机器人），无需修改模组，也不影响原版游戏按钮。

## 0.2.0 — 2026-11-20

- 发布适用于《机械派对》v2.1.2 的 Windows x64 正式版。可安装和更新目录中的八个模组，也可在设置中还原 Steam 原版。
- 《机械派对》目前仅支持 Windows。macOS 管理器列入后续计划。

## 0.1.2-13 — 2026-11-20

- 在设置中还原 Steam 原版。管理器等待 Steam 验证成功、核对游戏指纹后清理受管模组。清理中断后可重新扫描同一副本继续。

## 0.1.2-12 — 2026-11-20

- 安装、更新或卸载模组时，管理器会先询问是否关闭所选的游戏副本。应用更新提示会等当前对话框关闭后再显示。
- 滚筒嘉年华 v0.1.4 更新了场地和倒数效果；玩家聚光灯 v0.1.0 可用 F8 开关本机角色的顶灯；房间机器人 v0.2.2 支持迪斯科躲避玩法。

## 0.1.2-11 — 2026-11-19

- 支持从签名目录安装独立高清和兼容的新第一方模组。
- 在“已安装”检查模组更新，核对版本和游戏副本后点“确认更新”才开始下载。Windows 安装程序支持英语、简体中文和繁体中文。

## 0.1.2-10 — 2026-11-19

- 在“已安装”中选择目标模组的“更新至”。管理器会校验新包，若替换在提交前失败，会恢复旧版。其他模组保留各自的版本。
- 滚筒嘉年华 v0.1.2 增加开场俯视镜头与角色落地。房间机器人 v0.1.5 将房主操作按钮对齐至右上角。

## 0.1.2-9 — 2026-11-19

- 旧版滚筒嘉年华在“已安装”只显示一条。卸载会核对该游戏副本的文件指纹，保留同仓库的其他模组。
- 在线目录换版或换包后，仍可卸载已装的 MPML 模组，确认窗口会显示本地版本。如果重新安装干净游戏后旧 MPML 记录显示“需要修复”，可从“查看原因”选择“卸载”清理记录。

## 0.1.2-8 — 2026-11-19

Windows 测试版 0.1.2-8 在移除最后一个受管模组前校验还原后的 PCK，为使用目录链接的模组保留共用加载器，并在替换 PCK 前再次确认游戏已关闭。

## 0.1.2-7 — 2026-11-19

Windows 测试版提供六款在线模组，从 Worker/R2 获取并验证作者原包，再准备 MPML。切换前显示并核对将移除的模组。

## 0.1.2-6 — 2026-11-19

移除特殊的「官方自研」界面角标与目录特例，使所有上架 R2 与目录 Worker 的模组（包括 `roller-carnival v0.1.0`）保持完全一致的目录结构、下载流程与卡片展示。

## 0.1.2-5 — 2026-11-19

Windows 测试版 `0.1.2-5` 为目录内全部五个模组（`Overtime v1.7`、`MachineParty+ v2.1.0`、`Broadcast 8P Freecam v0.91`、`Binary1936 八人模组 v1.5` 与 `滚筒嘉年华 v0.1.0`）开放 `v2.1.2` 测试安装流程，新增 `loader-files`、PowerShell、内置 Python 适配器与互斥冲突检测，并加入管理器洁净室 PCK 自动加载器（`pck_loader.rs` + `mpm_bootstrap.gd`）与无损还原。

### 新增

- 通过 `scripts/pack-mod.mjs` 将 `mods/<id>/` 下的模组（`roller-carnival v0.1.0`）确定性打包为 `.zip`，经由 R2 与 `services/catalog-worker` 统一分发，与所有其他模组使用完全相同的下载与 SHA-256 校验流水线。

## 0.1.2-4 — 2026-11-19

Windows 测试版完善了安装结果与卸载结果弹窗状态展示、目录请求超时/断线自动重试机制，并在未配置代码签名证书时发布明确标记的未签名测试安装包。

### 变更

- 卸载改为分步弹窗流程，支持回读校验与失败重试；重新检测在找到 0 份或多份副本时保留现有的有效游戏目录。
- 设置页改为三段式语言切换控件；游戏目录面板将操作按钮右对齐且仅显示根路径与版本标签（移除冗余的“重新校验文件”按钮）；合并管理器与开源项目信息为单行，左侧点击跳转 GitHub 仓库，右侧显示版本号与静默更新提示红点。
- 移除顶部更新横幅按钮，改为每个新版自动弹出一次的非强制更新弹窗（若当前已有弹窗则顺延队列），并在有提供时展示更新说明。

## 0.1.2-3 — 2026-11-19

下载时关闭弹窗会中止传输并恢复安装按钮。套件沿用原有镜像并支持边缘缓存。列表项目来自远端目录，同步失败可直接重试。离线显示上次成功同步的数据时会标明来源。

## 0.1.2-2 — 2026-11-19

Windows 测试版支持在指定的 v2.1.2 游戏副本上测试 Overtime v1.7。点「安装」时先确认游戏目录。选好副本后，弹窗会自动下载、校验并安装；已有缓存可直接离线安装。操作前请完全退出游戏。其他模组在取得对应版本的依据之前显示「支持版本待确认」。

## 0.1.2-1 — 2026-11-19

Windows x64 测试版可用于检查新版界面、在线模组目录、游戏目录检测和各副本的状态。此测试版开放随包 Overtime v1.7 的 Windows 安装与离线还原，供实机验证。

### 变更

- 仓库重组为 `apps/desktop`、`services/update-worker` 与 `catalog`。模组列表改由唯一的 `catalog/mods.json` 提供。玩家看不到任何变化。
- 文档提供英文、简体中文与繁体中文版本，并加入架构决策记录。

### 新增

- 贡献指南、安全与支持说明、Issue 与 PR 模板，以及每次推送都运行的源码检查。

## 0.1.1 — 2026-11-18

### 新增

- Apple Silicon Mac 版本，与 Windows 共用稳定通道的签名应用内更新。

## 0.1.0 — 2026-11-18

### 新增

- 首个原型：随包发布四个候选模组的目录，支持三语搜索、详情与作者链接。
- Steam 游戏检测、手动选择目录与按副本比较版本。
- Windows x64 的签名应用内更新，经项目的更新 Worker 提供。
