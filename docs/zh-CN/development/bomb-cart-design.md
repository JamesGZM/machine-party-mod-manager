# 重工炸弹推车（Bomb Cart）玩法与开发规格书

[English](../../en/development/bomb-cart-design.md) · **简体中文** · [繁體中文](../../zh-TW/development/bomb-cart-design.md)

本规格书定义基于 `mpm-core` 与 `team-party` 的纯双队轨道拔河／攻防自研小游戏模组 **`bomb-cart`（重工炸弹推车）** 的完整玩法规则、场地结构、联机同步、AI 行为与开发里程碑，并作为后续实现的唯一设计基准。

## 1. 模组定位与准入声明

- **模组 ID**：`bomb-cart`（分类：`game`）
- **依赖模组**：`requires: ["mpm-core", "team-party"]`（必须同时于 [catalog/mods.json](../../../catalog/mods.json) 与 `mod.json` 声明）
- **槽位注册**：使用 `mpm-core` 的 `register_minigame()` 动态槽位（`>= 1000`），遵循[自研模组开发规范](mod-development.md)与[协作对抗小游戏规划与准入门槛规范](coop-minigame-gating.md)。
- **准入门槛声明（纯组队且严格限 2 队 `"team_only"`）**：

```gdscript
"admission": {
	"mode_support": "team_only",
	"min_teams": 2,
	"max_teams": 2,
	"min_total_players": 2,
	"min_players_per_team": 1,
	"allow_local_couch": false,
}
```

- **门槛行为**：
  - `bomb-cart` 是第一款在联机大厅实战验证 `max_teams: 2` 硬门槛的模组：当 `team-party` 设为 3–4 队时，大厅左侧列表自动灰化锁定并标注 `[限 2 队]`。
  - 未开启 `team-party`（FFA）或处于本地同屏模式时，大厅左侧列表自动灰化锁定（显示 `[需组队]` / `[仅联机]`），且不进入默认模式、街机模式或 15 格 CRT 转盘。
- **不对称人数与断线逆境补偿**：
  - 允许房主以“1v2”等不对称人数开局，或应对局中玩家断线；当两队当前存活人数不同时，人数较少的一方自动获得比例推力权重补偿（`clampf(larger / smaller, 1.0, 1.5)`）。
  - 若场上仅剩 1 支有效队伍仍有在线成员，立即触发该队提前胜出与同步结算。

## 2. 核心玩法循环、三阶段升级与胜负规则

对局采用**服务器权威（Host-Authoritative）**，总计 **3 秒准备 + 75 秒正式对抗**（若第 75 秒结束时仍卡在中线 `|cart_x| <= 0.15m`，则进入 **10 秒加时骤死**）：

1. **准备阶段（3 秒）**：
   - 第 1 队（红队）于西侧防爆闸门（`-11.5m`）前成列出生，第 2 队（蓝队）于东侧防爆闸门（`+11.5m`）前成列出生。
   - 镜头带过中央钢轨、停在 `x = 0` 的重工炸弹推车与南北两侧蒸汽增压阀，HUD 显示队伍颜色、进攻方向与目标提示。
2. **第一阶段：标准推进（0–40 秒）**：
   - 推车基础推速倍率 `1.0×`；南北两侧蒸汽增压阀每隔 `14 秒`轮流充能启动 1 座，供双方派出侧翼游击手争夺。
3. **第二阶段：引信点燃（40–60 秒）**：
   - 推车基础推速提升至 `1.35×`，打破中场胶着。
   - 炸弹本体每隔 `8 秒`触发一次**过载脉冲**：先于地面投射 **`1.2 秒`红色危险警示圈（半径 `3.2m`）**，倒数结束后释放冲击波，将圈内来不及退开的玩家震退并造成 `0.35 秒`硬直。
4. **第三阶段：临界过载（60–75 秒）**：
   - 推车基础推速提升至 `1.75×`，**南北两座蒸汽增压阀同时启动**且冷却缩短为 `10 秒`循环；弹头闪烁急促红光与警报声，提供最后 15 秒极限翻盘窗口。
5. **胜负判定与同步计分**：
   - **爆门秒杀（Instant KO）**：将炸弹推车推撞至敌方防爆闸门即刻引爆胜出——推达 `x >= +11.5m`（蓝方闸门）由红队胜出；推达 `x <= -11.5m`（红方闸门）由蓝队胜出。
   - **倒数引爆决胜（75 秒）**：时间归零未爆门时，炸弹就地引爆——车体位于哪一方半场即判该方落败（`x > +0.15m` 红胜、`x < -0.15m` 蓝胜）。
   - **加时骤死（10 秒）**：若 `t = 75s` 时 `|cart_x| <= 0.15m`，进入 10 秒骤死延长赛，率先将车推过 `±0.6m` 的队伍胜出；若仍平手则依整局最大推进深度（`max_abs_push`）判定。
   - 最终通过 `team-party` 的 Squads 同步计分回写房间总榜。

## 3. 操作、推进物理、重击助推与蒸汽增压阀

延续 Machine Party 纯键盘极简操作（`WASD` / 方向键 + `Space`）：

| 输入 | 行为说明 |
| --- | --- |
| `WASD` / 方向键 | 移动与转向（`6.6 m/s`）。进入炸弹推车 **`2.6m` 推进光环**即自动朝敌方闸门方向施加推力；光环颜色随净推力归属实时变换（红光／蓝光／僵持黄色火花）。净人数优势超过 `+2` 后采用边际递减曲线，确保 4v4 维持拉锯感而不致瞬间滑走。 |
| `Space`（共享 `0.95s` 冷却，按情境优先级触发） | 1. **工业推搡**：若前方扇形（`2.1m`）内有敌人，将其震出推进区并造成 `0.45s` 硬直与 `8.5 m/s` 击退；对同队队友**零伤害／零推开**（经 `team_support.are_teammates` 过滤）。<br>2. **重击助推（Power Ram）**：若附近无敌人但距离推车 `<= 2.4m`，猛撞推车给予一段爆发速度＋金属火花特效。<br>3. **快速拍阀**：若人正位于已启动的蒸汽增压阀踏板上，立即拍下触发（否则站上踏板 `0.6s` 亦会自动触发）。 |

### 蒸汽增压阀规则（南北侧翼机关）
- 南北各设 1 座高压蒸汽阀踏板，启动时伴随地面发光压力环与输气管线预热。
- 任一队成员抢先踩满 `0.6s` 或按 `Space` 拍下后，高压蒸汽沿地板管线喷入中央轨道：
  - 为触发队伍提供 **`2.5 秒`火箭推进（Rocket Surge）**，大幅朝敌方闸门加速冲刺。
  - 同时在推车周围 `2.8m` 产生气浪震退贴近的敌人，随即该阀门进入冷却等待下一轮启动。

## 4. 场地布局与视觉辨识（`26m × 16m` 轨道厂房）

- **镜头与场地边界**：俯视微斜角镜头完整收录东西向对推战线（`X: -13m..+13m`、`Z: -8m..+8m`），四周设工业护栏防止跌落。
- **中央重型钢轨（`X: -11.5m..+11.5m`）**：
  - 地面绘有 `25%`、`50%`（中线）、`75%` 距离刻度箭头，并随推车位置点亮对应队色的轨道指示灯。
- **东西两端防爆闸门**：
  - 西侧红队闸门（`-11.5m`）与东侧蓝队闸门（`+11.5m`）设有警戒灯柱；当推车逼近至 `3.5m` 内时灯柱加速闪烁红警报。
- **障碍与侧翼动线**：
  - 场内对称配置 4 根工业缓冲柱（`(±5.5, ±3.8)`），将战场自然切分为中央推进线与北侧 `(0, -6.0)`、南侧 `(0, +6.0)` 两条侧翼抢阀动线。
- **炸弹推车造型与反馈**：
  - 钢铁轨道底盘、随 `cart_vel` 转动的车轮、带阶段发光强度的重型弹头圆柱，以及贴地推进光环与阶段二／三冲击波警示环。

## 5. 联机权威与 20 Hz 状态同步

- **房主权威模拟（`multiplayer.is_server()`）**：
  - 所有玩家坐标／硬直、推车位置／速度／火箭推进计时、冲击波预警与引爆、蒸汽阀状态及胜负结果均由房主统一计算。
- **输入与快照 RPC**：
  - 客机上行：`move_dir: Vector2` 与 `action_pressed: bool`（沿用轻量输入 RPC 模式）。
  - 房主下行：约 `20 Hz`（`0.05s`）广播精简快照，包含 `cart_x`、`cart_vel`、`cart_owner`、`surge_team`、`surge_timer`、`pulse_state`／`pulse_timer`、`valve_states`（南／北）、`phase`、`time_left`、`overtime` 与各玩家 `{pos, yaw, stun, ram_cd}`。

## 6. `lobby-bots` AI 控制器设计（`ai_controller.gd`）

每个机器人依局势动态切换 3 种微角色，让 2v2 至 4v4 混编机器人时能打出场内分工与反制：

1. **阀门游击手（Valve Flanker）**：场上有启动中的蒸汽阀且没有更近的队友前往时，指派 1 名机器人全速冲往侧翼拍阀（但若推车距离自家闸门 `< 3.0m`，优先回防推车）。
2. **推车／助推手（Cart Pusher / Rammer）**：切入推车己方后侧的推进光环内朝敌门推车，周围无敌人时使用 `Space` 发动 Power Ram 助推；在阶段二／三炸弹冲击波预警的最后 `0.45s` 主动退至 `> 3.4m` 闪避。
3. **清场拦截手（Brawler / Blocker）**：检测到敌人正在光环内顶车或抢先跑向亮灯阀门时，主动贴近并按 `Space` 发动工业推搡将其震开轨道。

## 7. 模组文件结构与性能红线

```text
mods/bomb-cart/
├── mod.json                 # id: "bomb-cart", requires: ["mpm-core", "team-party"]
├── main.gd                  # _mod_init / _mod_ready、注册 max_teams: 2 admission 与场景替换
├── config.gd                # 平衡常数、颜色、阶段时间、推进力与场地几何辅助函数
├── official_minigame.gd     # 对接原版 Minigame 信号接口
├── bomb_cart_game.gd        # 服务器权威主逻辑、推车物理、蒸汽阀、脉冲与结算
├── arena_meshes.gd          # 轨道厂房、防爆闸门、缓冲柱、蒸汽阀与炸弹推车网格构建
├── ai_controller.gd         # lobby-bots 三角色协作与闪避 AI
├── fx_pool.gd               # 基于 mpm-core.create_fx_pool() 的火花／蒸汽／脉冲／爆门特效池
├── hud_ui.gd                # 顶部拉锯进度条（红 [===💣===] 蓝）、阶段警报与倒数计时
├── team_support.gd          # 复制自 mods/_shared/team-support/team_support.gd
├── self_test.gd             # --self-test 无头逻辑与边界验证
└── README.md                # 模组说明文件
```

### 性能与契约红线（对齐[自研模组开发规范](mod-development.md)）
- **零运行期配置**：所有火花、蒸汽喷流、脉冲冲击波与爆门爆炸特效均通过 `mpm-core.create_fx_pool()` 预建，并于 3 秒准备期在相机视锥内以极小缩放预热着色器。
- **热路径禁令**：`_process` / `_physics_process` 禁止调用 `get_property_list()`、禁止新建 `Mesh` / `StandardMaterial3D` 或 `queue_free()`。
- **无头与 Lint 规范**：通过 `node scripts/mod-lint.mjs`、不可对 `call()` / `get()` / `get_meta()` 使用无类型 `:=`。
