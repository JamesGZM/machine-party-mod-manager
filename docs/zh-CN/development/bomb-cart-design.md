# 重工炸弹推车（Bomb Cart）玩法与开发规格书

[English](../../en/development/bomb-cart-design.md) · **简体中文** · [繁體中文](../../zh-TW/development/bomb-cart-design.md)

本规格书定义基于 `mpm-core` 与 `team-party` 的 2–4 队自适应轨道攻防自研小游戏模组 **`bomb-cart`（重工炸弹推车）** 的完整玩法规则、自适应转盘场地、重工视觉风格、联机同步、AI 行为与开发里程碑。

## 1. 模组定位与准入声明

- **模组 ID**：`bomb-cart`（分类：`game`）
- **依赖模组**：`requires: ["mpm-core", "team-party"]`（必须同时于 [catalog/mods.json](../../../catalog/mods.json) 与 `mod.json` 声明）
- **槽位注册**：使用 `mpm-core` 的 `register_minigame()` 动态槽位（`>= 1000`），遵循[自研模组开发规范](mod-development.md)与[协作对抗小游戏规划与准入门槛规范](coop-minigame-gating.md)。
- **准入门槛声明（2–4 队 `"team_only"`）**：

```gdscript
"admission": {
	"mode_support": "team_only",
	"min_teams": 2,
	"max_teams": 4,
	"min_total_players": 2,
	"min_players_per_team": 1,
	"allow_local_couch": false,
}
```

- **门槛行为**：
  - `bomb-cart` 原生解锁 `team-party` 的 2 队（`2v2`/`4v4`）、3 队（`2v2v2`）与 4 队（`2v2v2v2`）联机房间，并根据实际队伍 ID（支持稀疏 ID 如 `[1, 3]`、`[2, 4]`）自动切换直轨、Y 型转盘或十字转盘场地。
  - 未开启 `team-party`（FFA）或处于本地同屏模式时，大厅左侧列表自动灰化锁定（显示 `[需组队]` / `[仅联机]`），且不进入默认模式、街机模式或 15 格 CRT 转盘。
- **不对称人数与断线逆境补偿**：
  - 允许房主以“1v2”等不对称人数开局，或应对局中玩家断线；当存活队伍人数不同时，人数较少的未破门队伍自动获得比例推力权重补偿（`clampf(larger / smaller, 1.0, 1.5)`）。
  - 若场上仅剩 1 支未破门队伍仍有在线成员，立即触发该队提前胜出与同步结算。

## 2. 核心玩法循环、三阶段升级与胜负规则

对局采用**服务器权威（Host-Authoritative）**，总计 **3 秒准备 + 75 秒正式对抗**（若第 75 秒结束时仍平局，则进入 **10 秒加时骤死**）：

1. **准备阶段（3 秒）**：
   - 各队于自家防爆闸门前成列出生并面朝中央钢轨／转盘枢纽。
   - 准备期及开局前约 `2.5s` 显示原版风格 `YOU` 框标追踪本地玩家，并配合居中粗描边 `3-2-1-GO!` 倒数。
2. **第一阶段：标准推进（0–40 秒）**：
   - 推车基础推速倍率 `1.0×`；蒸汽增压阀每隔 `14 秒`周期启动，供各队派出侧翼游击手争夺。
3. **第二阶段：引信点燃（40–60 秒）**：
   - 推车基础推速提升至 `1.35×`，打破中场胶着。
   - 炸弹本体每隔 `8 秒`触发一次**过载脉冲**：先于地面投射 **`1.2 秒`红色危险警示圈（半径 `3.2m`）**，倒数结束后释放冲击波，将圈内玩家震退并造成 `0.35 秒`硬直。
4. **第三阶段：临界过载（60–75 秒）**：
   - 推车基础推速提升至 `1.75×`，**所有蒸汽增压阀同时启动**且冷却缩短为 `10 秒`循环；弹头闪烁急促红光与警报声。
5. **胜负判定与同步计分**：
   - **2 队模式**：推达 `±11.5m` 敌方防爆闸门立即爆门秒杀；第 75 秒依半场归属（`±0.15m`）决胜，卡线则进 10 秒骤死（`±0.6m`）。
   - **3–4 队模式**：推车沿某支线抵达 `10.5m` 引爆该队防爆门时，该队全员立即标记 `alive = false`（淘汰并实时刷新 `team-party` 右上角 HUD），进攻队获得破门记分；若场上仍有 `>= 2` 支未破门队伍，推车重置回中央转盘 `(0, 0)` 并短暂暂停 `1.2s`，直至仅剩 1 支未破门队伍直接获胜。时间到时，未破门队伍严格高于已破门队伍，安全未破门队伍高于正被推车逼近的受威胁队伍（并按破门数排序）；若推车停在中央转盘且头部平分，则进入 10 秒骤死（推入任一敌方支线 `> 0.8m` 即决胜）。
   - 最终通过 `team-party` 的 Squads 同步计分回写房间总榜。

## 3. 操作、推进物理、重击助推与蒸汽增压阀

延续 Machine Party 纯键盘极简操作（`WASD` / 方向键 + `Space`）：

| 输入 | 行为说明 |
| --- | --- |
| `WASD` / 方向键 | 移动与转向（`6.6 m/s`）。进入炸弹推车 **`2.6m` 推进光环**即施加推力（2 队沿东西直轨对推；3–4 队在支线上防卫推回枢纽或压向敌门，在中央转盘依合力转向切入最契合的敌方未破门支线）。净优势超过 `+2` 采用边际递减曲线，确保 4v4 与 2v2v2v2 维持拉锯张力。 |
| `Space`（共享 `0.95s` 冷却，按情境优先级触发） | 1. **工业推搡**：若前方扇形（`2.1m`）内有敌人，将其震出推进区并造成 `0.45s` 硬直与 `8.5 m/s` 击退；对同队队友**零伤害／零推开**（经 `team_support.are_teammates` 过滤）。<br>2. **重击助推（Power Ram）**：若附近无敌人但距离推车 `<= 2.4m`，猛撞推车给予一段爆发速度＋金属火花特效。<br>3. **快速拍阀**：若人正位于已启动的蒸汽增压阀踏板上，立即拍下触发（否则无干扰站满 `0.6s` 自动触发）。 |

### 蒸汽增压阀规则（自适应侧翼机关）
- 2 队设南北 2 座阀门；3 队设 3 座扇区间对称阀门；4 队设 4 座对角侧翼阀门。
- 任一队抢先触发后，高压蒸汽沿地板管线喷入轨道／转盘：
  - 为触发队伍提供 **`2.5 秒`火箭推进（Rocket Surge）**，将推车远离己方闸门并沿敌方支线高速冲刺（若原本在己方支线，会先轰回转盘再切入最近敌方支线）。
  - 同时在推车周围 `2.8m` 产生气浪震退贴近的敌人，随即该阀门进入冷却。

## 4. 场地布局、重工铸造视觉与底部工业仪表 HUD

- **自适应轨道结构**：
  - **2 队（`26m × 16m`）**：东西向重型直轨（`±11.5m`）、东西防爆门、4 根缓冲柱 `(±5.5, ±3.8)` 与南北蒸汽阀 `(0, ±6.0)`。
  - **3 队（`26m × 26m`）**：中央重型钢铁转盘枢纽 `(0, 0)`、120° Y 型三支线钢轨（每条 `10.5m`）、3 座防爆门、3 根扇区缓冲柱与 3 座对称蒸汽阀。
  - **4 队（`26m × 26m`）**：中央重型钢铁转盘枢纽 `(0, 0)`、十字（+）四支线钢轨（每条 `10.5m`）、4 座防爆门、4 根中对角缓冲柱 `(±4.2, ±4.2)` 与 4 座对角蒸汽阀 `(±8.0, ±8.0)`。
- **重工铸造厂氛围与后处理**：
  - 暖色低饱和铁锈铸造厂光照（暖锈环境光、钨丝主光、熔炉琥珀补光）、下层工厂承台、带管线与铁笼壁灯的北侧高墙、**3D 场景化工业 CRT 时钟／阶段监视器**（`MM:SS` 与阶段提示），以及原版 `vignette.gdshader` + `posterization.gdshader` 后处理。
- **独立底部居中工业仪表 HUD**：
  - 右上角 100% 留白给 `team-party` 悬浮 HUD，不遮挡不重叠。
  - 底部居中零圆角黑钢琥珀边框仪表盘：2 队显示双向钢轨压力条与推车指针，3–4 队自动切换为紧凑**防爆门状态条**（`完好` / 威胁百分比 / `炸毁`），内置 CJK 字体回退与无边框粗描边警报文字。

## 5. 联机权威与 20 Hz 状态同步

- **房主权威模拟（`multiplayer.is_server()`）**：
  - 所有玩家坐标／硬直／存活状态、2D 推车坐标／速度／支线归属／转盘朝向／火箭推进计时、冲击波预警与引爆、蒸汽阀状态、各门存亡及排名结算均由房主统一计算。
- **输入与快照 RPC**：
  - 客机上行：轻量移动输入 RPC 与可靠动作 RPC。
  - 房主下行：约 `20 Hz`（`0.05s`）广播精简快照，包含 `cart_x`、`cart_pos`、`cart_vel`、`cart_vel_2d`、`cart_branch_team`、`cart_branch_dist`、`cart_angle`、`cart_reset_pause`、`door_alive`、`team_breaches`、`active_team_ids`、`surge_team`/`surge_timer`、`pulse_active`/`pulse_remaining`、`valves`、`phase`、`time_left`、`overtime` 与各玩家 `{pos, facing, stun, action_cd, alive}`。

## 6. `lobby-bots` AI 控制器设计（`ai_controller.gd`）

每个机器人在 2、3、4 队模式下动态切换 3 种微角色：

1. **阀门游击手（Valve Flanker）**：场上有启动中的蒸汽阀且没有更近的队友前往时，指派 1 名机器人全速冲往拍阀（但若推车逼近自家闸门则优先回防）。
2. **推车／助推手（Cart Pusher / Rammer）**：自家支线受威胁时立即回推，其余时刻切入推进光环后侧将推车压向敌方未破门支线，周围无敌人时发动 Power Ram；在阶段二／三冲击波预警最后 `0.45s` 主动退至 `> 3.6m` 闪避。
3. **清场拦截手（Brawler / Blocker）**：检测到敌人正在光环内顶车或抢阀时，主动贴近并按 `Space` 发动工业推搡。

## 7. 模组文件结构与性能红线

```text
mods/bomb-cart/
├── mod.json                 # id: "bomb-cart", requires: ["mpm-core", "team-party"]
├── main.gd                  # _mod_init / _mod_ready、注册 2-4 队 team_only 准入与场景
├── config.gd                # 平衡常数、4 队配色、自适应 2/3/4 队场地与碰撞几何
├── official_minigame.gd     # 对接原版 Minigame 信号接口
├── bomb_cart_game.gd        # 服务器权威主逻辑、2-4 队转盘物理、后处理与结算
├── arena_meshes.gd          # 重工铸造轨道厂房、2/3/4 支线转盘、3D CRT 监视器与推车网格
├── ai_controller.gd         # lobby-bots 2-4 队三角色协作与闪避 AI
├── fx_pool.gd               # 预分配火花／蒸汽／脉冲／爆门特效池
├── hud_ui.gd                # 底部零圆角工业仪表盘（2 队钢轨条 / 3-4 队闸门条）、YOU 标与大倒数
├── team_support.gd          # 复制自 mods/_shared/team-support/team_support.gd
├── self_test.gd             # --self-test 无头 2/3/4 队逻辑与压测验证
└── README.md                # 模组说明文件
```

### 性能与契约红线（对齐[自研模组开发规范](mod-development.md)）
- **零运行期配置**：所有火花、蒸汽喷流、脉冲冲击波与爆门爆炸特效均通过 `mpm-core.create_fx_pool()` 预建，并于 3 秒准备期在相机视锥内以极小缩放预热着色器。
- **热路径禁令**：`_process` / `_physics_process` 禁止调用 `get_property_list()`、禁止新建 `Mesh` / `StandardMaterial3D` 或 `queue_free()`。
- **无头与 Lint 规范**：通过 `node scripts/mod-lint.mjs`、不可对 `call()` / `get()` / `get_meta()` 使用无类型 `:=`。
