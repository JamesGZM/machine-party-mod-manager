[English](../../en/development/voltage-greed-design.md) · **简体中文** · [繁體中文](../../zh-TW/development/voltage-greed-design.md)

本规格书包含两部分内容：
1. **《机械狂欢》原味系列 3 款路线图**：围绕官方《餐桌礼仪（吃豆子）》所代表的黑色幽默近景舞台、极简按键贪心博弈与监工处决张力，规划 3 款适配 **2–8+ 人**、原生支持 **个人混战与 `team-party` 组队双模式（`both`）**、且 **无需语音开黑即可畅玩** 的系列新作。
2. **首款旗舰模组 `voltage-greed`（高压绩效）完整玩法与开发规格书**：涵盖 3 轮总分制、2 条命处决机制、仅限硬撑中触发的偷踹电压互害、工厂监控工况干扰、原生组队并联与敢死队战术、2–8 人近景舞台构图、净室资源复用、联机同步与开发里程碑。

## 1. 《机械狂欢》原味系列路线图

现有第一方小游戏（`roller-carnival`、`bubble-blitz`、`spike-ring`、`core-heist`、`bomb-cart`）以俯视或横版竞技场走位为主。**原味系列**将重心转向**近景舞台剧场感**：所有玩家同框坐镇圆桌或工位，帽饰、表情、手抖、甩锅动作与处决瞬间全部清晰可见。

## 3. 核心玩法循环、3 轮制、2 条命与计分规则

对局采用**房主权威模拟（Host-Authoritative）**，总时长约 **55 秒**，由 **3 秒准备 + 3 轮高压拉锯**（每轮 `12–16 秒`活跃阶段 + 约 `2.5 秒`处决与过场结算）组成：

1. **准备阶段（3 秒）**：
   - 全员锁在带编号的螺栓铁艺电椅上，统一面向正前方（`+Z`）对称近景机位，身后背靠高耸的中央巨型指针变压器、左上角 CRT 监控屏与右上角自动惩罚电弧发射器＋红色频闪警灯。
   - 准备期与第 1 轮前约 `2.5s` 显示原版 `YOU` 四角定位框追踪本地玩家，并播放粗描边 `3-2-1-GO!` 倒数。
2. **第 1 轮：基础班次（`1.0×` 绩效倍率）**：
   - 保持纯净基础规则、不插入随机工况，让新玩家 3 秒直观理解“按住刷分—松手锁分—硬撑踹电”。
3. **第 2 轮：高压班次（`1.25×` 绩效倍率）**：
   - 公共电压爬升加快，绩效获取提升至 `1.25×`，并触发 **1 次局中工厂监控工况干扰**。
4. **第 3 轮：临界加班（`1.5×–2.0×` 绩效倍率）**：
   - 基础倍率升至 `1.5×`（触发「双倍加班费」工况时高达 `2.0×`）并伴随 **1 次工况干扰**，让前两轮失手炸掉的玩家保留翻盘悬念。

### 隐藏过载阈值与渐进预警
- 每轮开始由房主秘密抽取该轮变压器的真实爆炸阈值，范围为 **`[70%, 100%]`**（引爆前绝不下发客户端）。
- 公共电压从 `0%` 随当前通电人数与 `S` 踹电持续攀升；跨越 `50%` → `70%` → `85%` 时，中央指针表剧烈抖动、头顶日光灯频闪、电缆迸出电弧并伴随低频嗡鸣加速。

### 2 条命处决结构与提前结束
- 每名玩家开局拥有 **2 条命**（具象化为电椅扶手上的 **2 颗保险丝灯泡**）。
- **第 1 次过载受炸（剩 1 条命）**：
  - 爆炸当下仍未松手的玩家被强电劈中，全身焦黑冒烟、帽子炸歪，**本轮未锁定的绩效分全部清零**，烧毁 1 颗保险丝，但仍可喘气进入下一轮。
- **第 2 次过载受炸（归零出局）**：
  - 电椅彻底过载炸毁，触发血花／火花喷溅与变压器爆破演出；该玩家本局**永久出局**（保留此前已锁定的总分，后续轮次不再得分）。
- **提前结算**：若第 1 或第 2 轮结束后，场存活玩家仅剩 `<= 1` 人（FFA）或仅剩 `<= 1` 支有效队伍（`team-party`），立即结束比赛并结算。

### 防摸鱼惩罚（工厂监控系统自动电罚）
- 若**场上所有存活玩家都在变压器爆炸前安全松手**，工厂自动监控系统立即闪亮后墙红灯警报，锁定本轮**绩效分最低者**（同分则惩罚最早松手逃跑的人）。
- 右上角惩罚电弧发射器向该玩家座椅劈下一道惩罚电弧并拉响警笛，直接**扣除其本轮已锁绩效分的 `50%`**（下限为 `0`），杜绝全员开局 0.2 秒秒退刷保底分。

## 4. 操作方式、硬撑专属偷踹（`S`）与工厂监控工况干扰

| 输入 | 行为说明 |
| --- | --- |
| **按住 `Space`**（或 `W` / `↑` / `action_1`） | **拉下电闸 / 刷绩效分**：电椅通电，本轮未锁定绩效分按加速曲线持续跳涨（公共电压越高，每秒涨幅倍率越高），同时推高公共过载表。 |
| **松开 `Space`** | **安全撤手 / 锁定分数**：电椅合上绝缘护罩，将本轮已刷到的绩效分永久存入总分，并免疫后续爆炸。松手后本轮不可再次通电。 |
| **点按 `S`**（或 `↓` / `action_2`，**每轮限 1 次，仅限硬撑时**） | **猛踹过载 / 赌命威吓**：**仅在当前仍按住 `Space` 通电硬撑时可用**；一旦松手锁定即禁用，避免安全旁观者无风险炸死别人。按下后立即向公共变压器注入 **`+12%` 过载电压**，同时让自己获得 **`1.8s` 个人绩效暴涨（`+35%` 速率）**，并伴随显眼的拍红开关动作、椅子连向总表的强光粗电弧与清脆跳闸声，全场清晰可见是谁在搞事。若 `+12%` 直接冲破隐藏阈值，包含踹电者在内的所有通电玩家当场一起炸飞。 |

### 局中工厂监控工况干扰（第 2、3 轮每轮随机触发 1 次）
1. **假报警（False Alarm）**：头顶红灯急闪、警笛尖啸 `1.2s`，同时真实电压短暂暂停攀升，专骗胆小鬼慌张松手。
2. **表针失灵（Glitching Meter）**：中央指针乱颤、CRT 读数花屏显示 `ERR // ???` 持续 `1.5s`，但真实电压仍在暗中照常上升，逼玩家盲撑博弈。
3. **双倍加班费（Double Overtime）**：金色厂铃响起 `2.5s`，期间绩效刷分速率直接翻倍（`2.0×`），引诱贪心鬼冲进高危红区。

## 5. 原生组队模式（`team-party`，`both`）规则

通过共享模块 `team_support.gd` 接入，未开启组队时自动零干扰退回个人混战：

- **席位编排与辨识**：同队成员在弧形席位中相邻就座，电椅底座带有队色涂装、头顶显示队伍前缀名牌，右上角由 `team-party` 实时展示各队存亡。
- **并联加速（Parallel Circuit）**：当同队有 **`>= 2` 名存活成员同时按住拉杆通电** 时，成员座椅之间产生明显的队色串联电弧，为本队正在通电的成员提供 **`+20%` 刷分加成**。
- **敢死队卖血战术（Kamikaze Sabotage）**：团队总分按队员已锁绩效累加并按 Squads 规则同步结算。当队友先安全松手锁下高分后，另一名敢死队员可故意留场硬撑并猛踹 `S`（`+12%`），主动引爆变压器把仍在贪分的敌队主力本轮绩效一锅端（以自己 1 颗保险丝换取敌队高分归零）。
- **单人队与掉线补偿**：若队伍开局仅 1 人或因淘汰／掉线减员至 1 名存活成员，自动获得 **`+10%` 单路补偿加成**，防止失去并联电弧后处于劣势。

## 6. 近景舞台构图、2–8 人机位与净室资源复用

- **自适应近景舞台（2–8+ 人正面朝向封闭厂房）**：
  - **2–4 人**：单排微弧形近景工位，全员统一面向正前方（`+Z`）对称居中机位，背后矗立中央巨型指针变压器、左上角 CRT 监视器与右上角自动惩罚电弧发射器＋红色频闪警灯；特写景别让每顶帽子、眼镜、全身颤抖、扶手保险丝灯泡与脚踏板迷你 LCD 分数清晰可读。
  - **5–8+ 人**：双排错位钢铁阶梯席位（后排抬高至 `y = 0.92` 并穿插在前排空隙中，两排均朝向 `+Z`），配合居中对称机位（`x = 0.0`），确保 8 名玩家、电弧连线与中央指针表同框清晰。
- **净室运行时资源复用（不提交原版资产）**：
  - 在挂载真实 `Machine Party.pck` 时动态加载原版纹理与资产（`green_pea` 封闭工业厂房墙板、铁椅/铁桌金属纹理、地板花纹、货架/纸箱/控制台，以及 `sitting_on_dinner_chair_idle.res` 与 `main character2.glb`＋`CustomizationAssigner` 配饰）；在 macOS 独立预览（`run_mac.sh`）下自动降级为程序化网格与材质。
  - 原版 `vignette.gdshader` + `posterization.gdshader` 后处理（`SCREEN_WIDTH=320`、`12` 阶色阶与双冷青顶部点光池），以及交由 `mpm-core.create_fx_pool()` 池化的原版喷血／火花／爆炸粒子。
- **场景化 HUD（Diegetic-First）**：
  - 后方中央 3D 嵌入式指针电压表 + 左上角 3D CRT 监视器（显示电压百分比、轮次与状态）+ 右上角自动惩罚电弧发射器与警灯；每把电椅脚踏板嵌入迷你 LCD，实时跳动本轮未锁分、已锁总分与 2 颗保险丝状态。
  - 屏幕右上角 100% 留白给 `team-party` HUD；底部居中仅放紧凑按键条（`按住 [Space] 刷分` · `松手锁分` · `[S] +12% 踹电`）。

## 7. 房主权威联机与 20 Hz 快照同步

- **房主权威（`multiplayer.is_server()`）**：秘密阈值抽取、公共电压积分、通电/锁分/受炸状态、仅限通电时的 `S` 踹电校验、工况调度、垫底点名、2 命淘汰与排名结算全部由房主权威计算。
- **上行输入 RPC**：客机通过可靠 RPC 上报拉杆状态（`set_holding_rpc(holding: bool)`）与踹电动作（`trigger_kick_rpc()`）。
- **下行状态快照（约 `20 Hz`，`0.05s`）**：包含 `round_idx`、`phase`、`phase_timer`、`display_voltage`、`event_id`、`event_timer` 与各玩家 `{holding, bailed, alive, lives, round_kpi, total_kpi, kick_used, fried_round}`，配合可靠事件 RPC 同步爆炸、踹电弧光、惩罚电弧发射器电罚与轮次结算。

## 8. `lobby-bots` 机器人演技设计（`ai_controller.gd`）

每个机器人在开局时随机抽取隐藏性格（*稳健社畜*、*贪心赌狗*、*搞事狂魔*），对应不同目标撤手阈值（`52%–88%`）与拟真反应延迟：
- **对工况做出可观察的“演戏”**：机器人会在**假报警**时按一定概率受惊慌张松手，也会在**表针失灵**期间产生决策犹豫。
- **主动踹电策略**：
  - 个人混战：*搞事狂魔*在 `55%–75%` 区间且领先或接近时主动拍 `S` 施压；稳健型机器人看到别人踹电后会迅速收手保分。
  - 组队模式：当队友已锁定较高分数且敌方主力仍在 `68%` 以上高风险区硬撑时，拥有 2 条命的机器人会果断化身“敢死队”猛踹 `S` 尝试同归于尽。

- **热路径禁令**：`_process` / `_physics_process` 禁止调用 `get_property_list()`、禁止新建 `Mesh` / `StandardMaterial3D` 或 `queue_free()`。
- **无头与 Lint 规范**：必须通过 `node scripts/mod-lint.mjs`（禁止对 `call()` / `get()` / `get_meta()` 使用无类型 `:=`）。
