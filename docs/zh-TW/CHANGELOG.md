# 更新紀錄

[English](../../CHANGELOG.md) · [简体中文](../zh-CN/CHANGELOG.md) · **繁體中文**

記錄對玩家與貢獻者有影響的變化。版本號與桌面 App 一致。

## 0.2.7 — 2026-11-25

- 新增 **炸彈推車（Bomb Cart `v0.1.0`）**：嚴格限 2 隊（`max_teams: 2`）的 75 秒鐵軌拔河對抗小遊戲，支援三階段加速、強力撞車、南北蒸氣增壓閥門、震盪脈衝與 10 秒突然死亡加時。
- 新增 **能源搶奪戰（Core Heist `v0.1.0`）**：2–4 隊 75 秒能源搶奪對抗小遊戲，支援中央傳送帶供料、回收爐 3 秒磁吸鎖、過載偷家加分與雙人電磁共振搬運核心。
- 將 **能源搶奪戰** 與 **炸彈推車** 設為正式版可用，並由 **`mpm-core`（`v0.1.1`）** 准入門檻系統（`team_only`、`max_teams: 2` 大廳鎖定提示與空清單保底）及 **`team-party`（`v0.1.1`）** 提供完整組隊支援。

## 0.2.6 — 2026-11-23

- 新增 **組隊派對（Team Party `v0.1.0`）** 房間 2–4 隊分隊與換位模組及原版小遊戲團隊掛接，並為 **泡泡爆破（`v0.1.5`）**、**尖刺圓環（`v0.1.3`）**、**滾筒嘉年華（`v0.1.11`）** 內建原生小隊模式。
- 新增單模組**啟用 / 停用**開關，為**批量操作**模式補齊批量啟用/停用與前置依賴自動配置，並引入基於 **`mpm-core`（`v0.1.0`）** 的宣告式 `requires` 依賴管理（核心庫自動對玩家瀏覽頁隱藏）。
- 為 **組隊派對** 與 **玩家聚光燈** 補充 R2 封面圖。
- 完成桌面端與模組架構模組化（[ADR-017](architecture/ADR-017-modular-boundaries-and-core-runtime.md)）及模組開發 SDK（[ADR-018](architecture/ADR-018-mod-development-sdk.md)）。

## 0.2.5 — 2026-11-22

- 移除左側導覽欄與獨立的「已安裝」頁，改用吸頂精簡頂部列（標誌、搜尋框、重新整理按鈕與獨立設定彈窗入口），主列表全寬排布更開闊。
- 新增目錄篩選欄：提供帶即時聯動數量的狀態標籤（**全部**、**已安裝**、**未安裝**、**需要更新**，隨所選分類與搜尋詞即時變化）以及分類篩選（**擴展**、**遊戲**、**工具**、**畫質**），並最佳化目錄同步狀態橫幅。
- 在操作欄新增**批量操作模式**：進入後可勾選多張卡片或全選目前結果，直接執行**安裝**（自動涵蓋新裝與已有新版的更新）或**卸載**，序列沿用單模組安全校驗與遊戲關閉檢查，並提供確認框、逐項進度與成功 / 失敗 / 跳過彙總（參考 PR #3）。

## 0.2.4 — 2026-11-21

- 將模組卡片封面從桌面端內建前端資源移至選用的 Cloudflare R2 圖床並經由目錄 Worker 分發（[ADR-016](architecture/ADR-016-r2-mod-covers.md)），減少約 5.8 MB 安裝包體積，後續新增模組或更換封面無需重裝用戶端。
- 同步收錄 **尖刺圓環（Spike Ring `v0.1.0`）** 以及 **泡泡爆破（`v0.1.2`）**、**滾筒嘉年華（`v0.1.8`）**、**獨立高清（`v0.1.2`）**、**玩家聚光燈（`v0.1.1`）** 的執行流暢度最佳化版本。

## 0.2.3 — 2026-11-20

- 新增第一方 3D 派對小遊戲 **泡泡爆破（Bubble Blitz `v0.1.0`）**：每人 3 滴血（最後 1 血歸零進入 4 秒重傷瀕死可被撞擊處決，或由救命針自動自救），4 套隨機工業地圖含傳送帶，復用原版角色、爆炸粒子與 3D 工業道具，並配有底部僅自己可見的 CRT 屬性狀態欄。
- 新增**多小遊戲共存註冊中心**（[ADR-015](architecture/ADR-015-multi-minigame-hub.md)），同步將 **滾筒嘉年華（Roller Carnival）** 升級至 `v0.1.6`，現可與泡泡爆破及後續更多自研小遊戲同時安裝並在預設、自訂歌單、街機、本機同螢幕與過場 15 格 CRT 抽籤池中共存。

## 0.2.2 — 2026-11-20

- 內建模組載入器升級至 v5，支援辨識啟動階段延後掛載的常駐 HUD（如 MachineParty+ 右上角語音按鈕），穩定排開大廳重疊的模組按鈕且不影響原版按鈕。
- 設定頁新增內建載入器版本顯示與「重載載入器」按鈕；應用程式更新包含新版載入器時，會在遊戲關閉後自動完成載入器升級，無需重裝模組。

## 0.2.1 — 2026-11-20

- 內建模組載入器升級至 v4，自動排開大廳中互相重疊的模組按鈕（例如 MachineParty+ 與房間機器人），無需修改模組，也不影響原版遊戲按鈕。

## 0.2.0 — 2026-11-20

- 發布適用於《機械派對》v2.1.2 的 Windows x64 正式版。可安裝與更新目錄中的八個模組，也可在設定中還原 Steam 原版。
- 《機械派對》目前僅支援 Windows。macOS 管理器列入後續計畫。

## 0.1.2-13 — 2026-11-20

- 在設定中還原 Steam 原版。管理器等待 Steam 驗證成功、核對遊戲指紋後清理受管模組。清理中斷後可重新掃描同一副本續做。

## 0.1.2-12 — 2026-11-20

- 安裝、更新或解除安裝模組時，管理器會先詢問是否關閉所選的遊戲副本。應用程式更新提示會等目前的對話框關閉後再顯示。
- 滾筒嘉年華 v0.1.4 更新了場地與倒數效果；玩家聚光燈 v0.1.0 可用 F8 開關本機角色的頂燈；房間機器人 v0.2.2 支援迪斯可閃避玩法。

## 0.1.2-11 — 2026-11-19

- 支援從簽章目錄安裝獨立高清及相容的第一方新模組。
- 在「已安裝」檢查模組更新，核對版本與遊戲副本後點選「確認更新」才開始下載。Windows 安裝程式支援英文、簡體中文及繁體中文。

## 0.1.2-10 — 2026-11-19

- 在「已安裝」中選擇目標模組的「更新至」。管理器會校驗新套件，若替換在提交前失敗，會還原舊版。其他模組保留各自的版本。
- 滾筒嘉年華 v0.1.2 加入開場俯視鏡頭與角色落地。房間機器人 v0.1.5 將房主操作按鈕對齊至右上角。

## 0.1.2-9 — 2026-11-19

- 舊版滾筒嘉年華在「已安裝」只顯示一筆。解除安裝會核對該遊戲副本的檔案指紋，保留同倉庫的其他模組。
- 線上目錄換版或換包後，仍可解除安裝已裝的 MPML 模組，確認視窗會顯示本機版本。若重新安裝乾淨遊戲後舊 MPML 記錄顯示「需要修復」，可從「查看原因」選擇「解除安裝」清理記錄。

## 0.1.2-8 — 2026-11-19

Windows 測試版 0.1.2-8 在移除最後一個受管模組前驗證還原後的 PCK，為使用目錄連結的模組保留共用載入器，並在替換 PCK 前再次確認遊戲已關閉。

## 0.1.2-7 — 2026-11-19

Windows 測試版提供六款線上模組，從 Worker/R2 取得並驗證作者原包，再準備 MPML。切換前顯示並核對將移除的模組。

## 0.1.2-6 — 2026-11-19

移除特殊的「官方自研」介面標籤與目錄特例，使所有上架 R2 與目錄 Worker 的模組（包括 `roller-carnival v0.1.0`）維持完全一致的目錄結構、下載流程與卡片呈現。

## 0.1.2-5 — 2026-11-19

Windows 測試版 `0.1.2-5` 為目錄內全部五個模組（`Overtime v1.7`、`MachineParty+ v2.1.0`、`Broadcast 8P Freecam v0.91`、`Binary1936 八人模組 v1.5` 與 `滾筒嘉年華 v0.1.0`）開放 `v2.1.2` 測試安裝流程，新增 `loader-files`、PowerShell、內建 Python 適配器與互斥衝突偵測，並加入管理器潔淨室 PCK 自動載入器（`pck_loader.rs` + `mpm_bootstrap.gd`）與無損還原。

### 新增

- 透過 `scripts/pack-mod.mjs` 將 `mods/<id>/` 下的模組（`roller-carnival v0.1.0`）確定性打包為 `.zip`，經由 R2 與 `services/catalog-worker` 統一分發，與所有其他模組共用完全相同的下載與 SHA-256 校驗流程。

## 0.1.2-4 — 2026-11-19

Windows 測試版完善了安裝結果與解除安裝結果彈窗狀態顯示、目錄請求逾時／斷線自動重試機制，並在未設定程式碼簽署憑證時發布明確標記的未簽章測試安裝檔。

### 變更

- 解除安裝改為分步彈窗流程，支援讀回校驗與失敗重試；重新偵測在找到 0 份或多份副本時保留現有的有效遊戲目錄。
- 設定頁改為三段式語言切換控制項；遊戲目錄面板將操作按鈕右對齊且僅顯示根路徑與版本標籤（移除冗餘的「重新校驗檔案」按鈕）；合併管理器與開源專案資訊為單行，左側點擊跳轉 GitHub 倉庫，右側顯示版本號與靜默更新提示紅點。
- 移除頂部更新橫幅按鈕，改為每個新版自動彈出一次的非強制更新彈窗（若目前已有彈窗則順延排隊），並在有提供時顯示更新說明。

## 0.1.2-3 — 2026-11-19

下載時關閉彈窗會中止傳輸並恢復安裝按鈕。套件沿用原有鏡像並支援邊緣快取。列表項目來自遠端目錄，同步失敗可直接重試。離線顯示上次成功同步的資料時會標示來源。

## 0.1.2-2 — 2026-11-19

Windows 測試版可在指定的 v2.1.2 遊戲副本上測試 Overtime v1.7。點「安裝」時先確認遊戲目錄。選好副本後，彈窗會自動下載、校驗並安裝；已有快取可直接離線安裝。操作前請完全退出遊戲。其他模組取得對應版本的依據前會顯示「支援版本待確認」。

## 0.1.2-1 — 2026-11-19

Windows x64 測試版可用來檢查新版介面、線上模組目錄、遊戲目錄偵測和各副本的狀態。此測試版開放隨包 Overtime v1.7 的 Windows 安裝與離線還原，供實機驗證。

### 變更

- 倉庫重組為 `apps/desktop`、`services/update-worker` 與 `catalog`。模組清單改由唯一的 `catalog/mods.json` 提供。玩家看不到任何變化。
- 文件提供英文、簡體中文與繁體中文版本，並加入架構決策紀錄。

### 新增

- 貢獻指南、安全與支援說明、Issue 與 PR 範本，以及每次推送都執行的原始碼檢查。

## 0.1.1 — 2026-11-18

### 新增

- Apple Silicon Mac 版本，與 Windows 共用穩定通道的簽章應用程式內更新。

## 0.1.0 — 2026-11-18

### 新增

- 首個原型：隨包發布四個候選模組的目錄，支援三語搜尋、詳情與作者連結。
- Steam 遊戲偵測、手動選擇目錄與按副本比較版本。
- Windows x64 的簽章應用程式內更新，經專案的更新 Worker 提供。
