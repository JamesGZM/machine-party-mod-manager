# 重工炸彈推車（Bomb Cart）玩法與開發規格書

[English](../../en/development/bomb-cart-design.md) · [简体中文](../../zh-CN/development/bomb-cart-design.md) · **繁體中文**

本規格書定義基於 `mpm-core` 與 `team-party` 的 2–4 隊自適應軌道攻防自研小遊戲模組 **`bomb-cart`（重工炸彈推車）** 的完整玩法規則、自適應轉盤場地、重工視覺風格、連線同步、AI 行為與開發里程碑。

## 1. 模組定位與准入宣告

- **模組 ID**：`bomb-cart`（分類：`game`）
- **相依模組**：`requires: ["mpm-core", "team-party"]`（必須同時於 [catalog/mods.json](../../../catalog/mods.json) 與 `mod.json` 宣告）
- **槽位註冊**：使用 `mpm-core` 的 `register_minigame()` 動態槽位（`>= 1000`），依循[自研模組開發規範](mod-development.md)與[協作對抗小遊戲准入門檻規範](coop-minigame-gating.md)。
- **准入門檻宣告（2–4 隊 `"team_only"`）**：

```gdscript
"admission": {
	"mode_support": "team_only",
	"min_teams": 2,
	"max_teams": 4,
	"min_total_players": 2,
	"min_players_per_team": 1,
	"allow_local_couch": false,
}
```

- **門檻行為**：
  - `bomb-cart` 原生解鎖 `team-party` 的 2 隊（`2v2`/`4v4`）、3 隊（`2v2v2`）與 4 隊（`2v2v2v2`）連線房間，並根據實際隊伍 ID（支援稀疏 ID 如 `[1, 3]`、`[2, 4]`）自動切換直軌、Y 型轉盤或十字轉盤場地。
  - 未開啟 `team-party`（FFA）或處於本地同屏模式時，大廳左側清單自動灰化鎖定（顯示 `[需組隊]` / `[僅連線]`），且不進入預設模式、街機模式或 15 格 CRT 轉盤。
- **不對稱人數與斷線逆境補償**：
  - 允許房主以「1v2」等不對稱人數開局，或因應局中玩家斷線；當存活隊伍人數不同時，人數較少的未破門隊伍自動獲得比例推力權重補償（`clampf(larger / smaller, 1.0, 1.5)`）。
  - 若場上僅剩 1 支未破門隊伍仍有在線成員，立即觸發該隊提前勝出與同步結算。

## 2. 核心玩法循環、三階段升級與勝負規則

對局採**伺服器權威（Host-Authoritative）**，總計 **3 秒準備 + 75 秒正式對抗**（若第 75 秒結束時仍平局，則進入 **10 秒加時驟死**）：

1. **準備階段（3 秒）**：
   - 各隊於自家防爆閘門前成列出生並面朝中央鋼軌／轉盤樞紐。
   - 準備期及開局前約 `2.5s` 顯示原版風格 `YOU` 框標追蹤本地玩家，並配合置中粗描邊 `3-2-1-GO!` 倒數。
2. **第一階段：標準推進（0–40 秒）**：
   - 推車基礎推速倍率 `1.0×`；蒸氣增壓閥每隔 `14 秒`週期啟動，供各隊派出側翼游擊手爭奪。
3. **第二階段：引信點燃（40–60 秒）**：
   - 推車基礎推速提升至 `1.35×`，打破中場膠著。
   - 炸彈本體每隔 `8 秒`觸發一次**過載脈衝**：先於地面投射 **`1.2 秒`紅色危險警示圈（半徑 `3.2m`）**，倒數結束後釋放衝擊波，將圈內玩家震退並造成 `0.35 秒`硬直。
4. **第三階段：臨界過載（60–75 秒）**：
   - 推車基礎推速提升至 `1.75×`，**所有蒸氣增壓閥同時啟動**且冷卻縮短為 `10 秒`循環；彈頭閃爍急促紅光與警報聲。
5. **勝負判定與同步計分**：
   - **2 隊模式**：推達 `±11.5m` 敵方防爆閘門立即爆門秒殺；第 75 秒依半場歸屬（`±0.15m`）決勝，卡線則進 10 秒驟死（`±0.6m`）。
   - **3–4 隊模式**：推車沿某支線抵達 `10.5m` 引爆該隊防爆門時，該隊全員立即標記 `alive = false`（淘汰並即時更新 `team-party` 右上角 HUD），進攻隊獲得破門記分；若場上仍有 `>= 2` 支未破門隊伍，推車重置回中央轉盤 `(0, 0)` 並短暫暫停 `1.2s`，直至僅剩 1 支未破門隊伍直接獲勝。時間到時，未破門隊伍嚴格高於已破門隊伍，安全未破門隊伍高於正被推車逼近的受威脅隊伍（並依破門數排序）；若推車停在中央轉盤且頭部平分，則進入 10 秒驟死（推入任一敵方支線 `> 0.8m` 即決勝）。
   - 最終透過 `team-party` 的 Squads 同步計分回寫房間總榜。

## 3. 操作、推進物理、重擊助推與蒸氣增壓閥

延續 Machine Party 純鍵盤極簡操作（`WASD` / 方向鍵 + `Space`）：

| 輸入 | 行為說明 |
| --- | --- |
| `WASD` / 方向鍵 | 移動與轉向（`6.6 m/s`）。進入炸彈推車 **`2.6m` 推進光環**即施加推力（2 隊沿東西直軌對推；3–4 隊在支線上防衛推回樞紐或壓向敵門，在中央轉盤依合力轉向切入最契合的敵方未破門支線）。淨優勢超過 `+2` 採邊際遞減曲線，確保 4v4 與 2v2v2v2 維持拉鋸張力。 |
| `Space`（共享 `0.95s` 冷卻，依情境優先順序觸發） | 1. **工業推搡**：若前方扇形（`2.1m`）內有敵人，將其震出推進區並造成 `0.45s` 硬直與 `8.5 m/s` 擊退；對同隊隊友**零傷害／零推開**（經 `team_support.are_teammates` 過濾）。<br>2. **重擊助推（Power Ram）**：若附近無敵人但距離推車 `<= 2.4m`，猛撞推車給予一段爆發速度＋金屬火花特效。<br>3. **快速拍閥**：若人正位於已啟動的蒸氣增壓閥踏板上，立即拍下觸發（否則無干擾站滿 `0.6s` 自動觸發）。 |

### 蒸氣增壓閥規則（自適應側翼機關）
- 2 隊設南北 2 座閥門；3 隊設 3 座扇區間對稱閥門；4 隊設 4 座對角側翼閥門。
- 任一隊搶先觸發後，高壓蒸氣沿地板管線噴入軌道／轉盤：
  - 為觸發隊伍提供 **`2.5 秒`火箭推進（Rocket Surge）**，將推車遠離己方閘門並沿敵方支線高速衝刺（若原本在己方支線，會先轟回轉盤再切入最近敵方支線）。
  - 同時在推車周圍 `2.8m` 產生氣浪震退貼近的敵人，隨即該閥門進入冷卻。

## 4. 場地佈局、重工鑄造視覺與底部工業儀表 HUD

- **自適應軌道結構**：
  - **2 隊（`26m × 16m`）**：東西向重型直軌（`±11.5m`）、東西防爆門、4 根緩衝柱 `(±5.5, ±3.8)` 與南北蒸氣閥 `(0, ±6.0)`。
  - **3 隊（`26m × 26m`）**：中央重型鋼鐵轉盤樞紐 `(0, 0)`、120° Y 型三支線鋼軌（每條 `10.5m`）、3 座防爆門、3 根扇區緩衝柱與 3 座對稱蒸氣閥。
  - **4 隊（`26m × 26m`）**：中央重型鋼鐵轉盤樞紐 `(0, 0)`、十字（+）四支線鋼軌（每條 `10.5m`）、4 座防爆門、4 根中對角緩衝柱 `(±4.2, ±4.2)` 與 4 座對角蒸氣閥 `(±8.0, ±8.0)`。
- **重工鑄造廠氛圍與後處理**：
  - 暖色低飽和鐵鏽鑄造廠光照（暖鏽環境光、鎢絲主光、熔爐琥珀補光）、下層工廠承台、帶管線與鐵籠壁燈的北側高牆、**3D 場景化工業 CRT 時鐘／階段監視器**（`MM:SS` 與階段提示），以及原版 `vignette.gdshader` + `posterization.gdshader` 後處理。
- **獨立底部置中工業儀表 HUD**：
  - 右上角 100% 留白給 `team-party` 懸浮 HUD，不遮擋不重疊。
  - 底部置中零圓角黑鋼琥珀邊框儀表盤：2 隊顯示雙向鋼軌壓力條與推車指針，3–4 隊自動切換為緊湊**防爆門狀態條**（`完好` / 威脅百分比 / `炸毀`），內建 CJK 字體回退與無邊框粗描邊警報文字。

## 5. 連線權威與 20 Hz 狀態同步

- **房主權威模擬（`multiplayer.is_server()`）**：
  - 所有玩家座標／硬直／存活狀態、2D 推車座標／速度／支線歸屬／轉盤朝向／火箭推進計時、衝擊波預警與引爆、蒸氣閥狀態、各門存亡及排名結算均由房主統一計算。
- **輸入與快照 RPC**：
  - 客機上行：輕量移動輸入 RPC 與可靠動作 RPC。
  - 房主下行：約 `20 Hz`（`0.05s`）廣播精簡快照，包含 `cart_x`、`cart_pos`、`cart_vel`、`cart_vel_2d`、`cart_branch_team`、`cart_branch_dist`、`cart_angle`、`cart_reset_pause`、`door_alive`、`team_breaches`、`active_team_ids`、`surge_team`/`surge_timer`、`pulse_active`/`pulse_remaining`、`valves`、`phase`、`time_left`、`overtime` 與各玩家 `{pos, facing, stun, action_cd, alive}`。

## 6. `lobby-bots` AI 控制器設計（`ai_controller.gd`）

每個機器人在 2、3、4 隊模式下動態切換 3 種微角色：

1. **閥門游擊手（Valve Flanker）**：場上有啟動中的蒸氣閥且沒有更近的隊友前往時，指派 1 名機器人全速衝往拍閥（但若推車逼近自家閘門則優先回防）。
2. **推車／助推手（Cart Pusher / Rammer）**：自家支線受威脅時立即回推，其餘時刻切入推進光環後側將推車壓向敵方未破門支線，周圍無敵人時發動 Power Ram；在階段二／三衝擊波預警最後 `0.45s` 主動退至 `> 3.6m` 閃避。
3. **清場攔截手（Brawler / Blocker）**：偵測到敵人正在光環內頂車或搶閥時，主動貼近並按 `Space` 發動工業推搡。

## 7. 模組檔案結構與效能紅線

```text
mods/bomb-cart/
├── mod.json                 # id: "bomb-cart", requires: ["mpm-core", "team-party"]
├── main.gd                  # _mod_init / _mod_ready、註冊 2-4 隊 team_only 准入與場景
├── config.gd                # 平衡常數、4 隊配色、自適應 2/3/4 隊場地與碰撞幾何
├── official_minigame.gd     # 對接原版 Minigame 訊號介面
├── bomb_cart_game.gd        # 伺服器權威主邏輯、2-4 隊轉盤物理、後處理與結算
├── arena_meshes.gd          # 重工鑄造軌道廠房、2/3/4 支線轉盤、3D CRT 監視器與推車網格
├── ai_controller.gd         # lobby-bots 2-4 隊三角色協作與閃避 AI
├── fx_pool.gd               # 預分配火花／蒸氣／脈衝／爆門特效池
├── hud_ui.gd                # 底部零圓角工業儀表盤（2 隊鋼軌條 / 3-4 隊閘門條）、YOU 標與大倒數
├── team_support.gd          # 複製自 mods/_shared/team-support/team_support.gd
├── self_test.gd             # --self-test 無頭 2/3/4 隊邏輯與壓測驗證
└── README.md                # 模組說明文件
```

### 效能與契約紅線（對齊[自研模組開發規範](mod-development.md)）
- **零執行期配置**：所有火花、蒸氣噴流、脈衝衝擊波與爆門爆炸特效均透過 `mpm-core.create_fx_pool()` 預建，並於 3 秒準備期在相機視錐內以極小縮放預熱著色器。
- **熱路徑禁令**：`_process` / `_physics_process` 禁止呼叫 `get_property_list()`、禁止新建 `Mesh` / `StandardMaterial3D` 或 `queue_free()`。
- **無頭與 Lint 規範**：通過 `node scripts/mod-lint.mjs`、不可對 `call()` / `get()` / `get_meta()` 使用無型別 `:=`。

| 里程碑 | 交付項目 | 驗收標準 |

| **M1：骨架與軌道場地** | `mod.json`、`main.gd`、`config.gd`、`arena_meshes.gd`、註冊 `max_teams: 2` admission | 通過 `mpm-core` 准入檢查（FFA／本地同屏／3–4 隊皆正確鎖定，2 隊正常開放）；場地、防爆門與推車網格無重疊 |
