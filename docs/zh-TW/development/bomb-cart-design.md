# 重工炸彈推車（Bomb Cart）玩法與開發規格書

[English](../../en/development/bomb-cart-design.md) · [简体中文](../../zh-CN/development/bomb-cart-design.md) · **繁體中文**

本規格書定義基於 `mpm-core` 與 `team-party` 的純雙隊軌道拔河／攻防自研小遊戲模組 **`bomb-cart`（重工炸彈推車）** 的完整玩法規則、場地結構、連線同步、AI 行為與開發里程碑，並作為後續實作的唯一設計基準。

## 1. 模組定位與准入宣告

- **模組 ID**：`bomb-cart`（分類：`game`）
- **相依模組**：`requires: ["mpm-core", "team-party"]`（必須同時於 [catalog/mods.json](../../../catalog/mods.json) 與 `mod.json` 宣告）
- **槽位註冊**：使用 `mpm-core` 的 `register_minigame()` 動態槽位（`>= 1000`），依循[自研模組開發規範](mod-development.md)與[協作對抗小遊戲准入門檻規範](coop-minigame-gating.md)。
- **准入門檻宣告（純組隊且嚴格限 2 隊 `"team_only"`）**：

```gdscript
"admission": {
	"mode_support": "team_only",
	"min_teams": 2,
	"max_teams": 2,
	"min_total_players": 2,
	"min_players_per_team": 1,
	"allow_local_couch": false,
}
```

- **門檻行為**：
  - `bomb-cart` 是第一款在線上大廳實戰驗證 `max_teams: 2` 硬門檻的模組：當 `team-party` 設定為 3–4 隊時，大廳左側清單自動灰化鎖定並標註 `[限 2 隊]`。
  - 未開啟 `team-party`（FFA）或處於本地同屏模式時，大廳左側清單自動灰化鎖定（顯示 `[需組隊]` / `[僅連線]`），且不進入預設模式、街機模式或 15 格 CRT 轉盤。
- **不對稱人數與斷線逆境補償**：
  - 允許房主以「1v2」等不對稱人數開局，或因應局中玩家斷線；當兩隊當下存活人數不同時，人數較少的一方自動獲得比例推力權重補償（`clampf(larger / smaller, 1.0, 1.5)`）。
  - 若場上僅剩 1 支有效隊伍仍有在線成員，立即觸發該隊提前勝出與同步結算。

## 2. 核心玩法循環、三階段升級與勝負規則

對局採**伺服器權威（Host-Authoritative）**，總計 **3 秒準備 + 75 秒正式對抗**（若第 75 秒結束時仍卡在中線 `|cart_x| <= 0.15m`，則進入 **10 秒加時驟死**）：

1. **準備階段（3 秒）**：
   - 第 1 隊（紅隊）於西側防爆閘門（`-11.5m`）前成列出生，第 2 隊（藍隊）於東側防爆閘門（`+11.5m`）前成列出生。
   - 鏡頭帶過中央鋼軌、停在 `x = 0` 的重工炸彈推車與南北兩側蒸氣增壓閥，HUD 顯示隊伍顏色、進攻方向與目標提示。
2. **第一階段：標準推進（0–40 秒）**：
   - 推車基礎推速倍率 `1.0×`；南北兩側蒸氣增壓閥每隔 `14 秒`輪流充能啟動 1 座，供雙方派出側翼游擊手爭奪。
3. **第二階段：引信點燃（40–60 秒）**：
   - 推車基礎推速提升至 `1.35×`，打破中場膠著。
   - 炸彈本體每隔 `8 秒`觸發一次**過載脈衝**：先於地面投射 **`1.2 秒`紅色危險警示圈（半徑 `3.2m`）**，倒數結束後釋放衝擊波，將圈內來不及退開的玩家震退並造成 `0.35 秒`硬直。
4. **第三階段：臨界過載（60–75 秒）**：
   - 推車基礎推速提升至 `1.75×`，**南北兩座蒸氣增壓閥同時啟動**且冷卻縮短為 `10 秒`循環；彈頭閃爍急促紅光與警報聲，提供最後 15 秒極限翻盤窗口。
5. **勝負判定與同步計分**：
   - **爆門秒殺（Instant KO）**：將炸彈推車推撞至敵方防爆閘門即刻引爆勝出——推達 `x >= +11.5m`（藍方閘門）由紅隊勝出；推達 `x <= -11.5m`（紅方閘門）由藍隊勝出。
   - **倒數引爆決勝（75 秒）**：時間歸零未爆門時，炸彈就地引爆——車體位於哪一方半場即判該方落敗（`x > +0.15m` 紅勝、`x < -0.15m` 藍勝）。
   - **加時驟死（10 秒）**：若 `t = 75s` 時 `|cart_x| <= 0.15m`，進入 10 秒驟死延長賽，率先將車推過 `±0.6m` 的隊伍勝出；若仍平手則依整局最大推進深度（`max_abs_push`）判定。
   - 最終透過 `team-party` 的 Squads 同步計分回寫房間總榜。

## 3. 操作、推進物理、重擊助推與蒸氣增壓閥

延續 Machine Party 純鍵盤極簡操作（`WASD` / 方向鍵 + `Space`）：

| 輸入 | 行為說明 |
| --- | --- |
| `WASD` / 方向鍵 | 移動與轉向（`6.6 m/s`）。進入炸彈推車 **`2.6m` 推進光環**即自動朝敵方閘門方向施加推力；光環顏色隨淨推力歸屬即時變換（紅光／藍光／僵持黃色火花）。淨人數優勢超過 `+2` 後採邊際遞減曲線，確保 4v4 維持拉鋸感而不致瞬間滑走。 |
| `Space`（共享 `0.95s` 冷卻，依情境優先順序觸發） | 1. **工業推搡**：若前方扇形（`2.1m`）內有敵人，將其震出推進區並造成 `0.45s` 硬直與 `8.5 m/s` 擊退；對同隊隊友**零傷害／零推開**（經 `team_support.are_teammates` 過濾）。<br>2. **重擊助推（Power Ram）**：若附近無敵人但距離推車 `<= 2.4m`，猛撞推車給予一段爆發速度＋金屬火花特效。<br>3. **快速拍閥**：若人正位於已啟動的蒸氣增壓閥踏板上，立即拍下觸發（否則站上踏板 `0.6s` 亦會自動觸發）。 |

### 蒸氣增壓閥規則（南北側翼機關）
- 南北各設 1 座高壓蒸氣閥踏板，啟動時伴隨地面發光壓力環與輸氣管線預熱。
- 任一隊成員搶先踩滿 `0.6s` 或按 `Space` 拍下後，高壓蒸氣沿地板管線噴入中央軌道：
  - 為觸發隊伍提供 **`2.5 秒`火箭推進（Rocket Surge）**，大幅朝敵方閘門加速衝刺。
  - 同時在推車周圍 `2.8m` 產生氣浪震退貼近的敵人，隨即該閥門進入冷卻等待下一輪啟動。

## 4. 場地佈局與視覺辨識（`26m × 16m` 軌道廠房）

- **鏡頭與場地邊界**：俯視微斜角鏡頭完整收錄東西向對推戰線（`X: -13m..+13m`、`Z: -8m..+8m`），四周設工業護欄防止跌落。
- **中央重型鋼軌（`X: -11.5m..+11.5m`）**：
  - 地面繪有 `25%`、`50%`（中線）、`75%` 距離刻度箭頭，並隨推車位置點亮對應隊色的軌道指示燈。
- **東西兩端防爆閘門**：
  - 西側紅隊閘門（`-11.5m`）與東側藍隊閘門（`+11.5m`）設有警戒燈柱；當推車逼近至 `3.5m` 內時燈柱加速閃爍紅警報。
- **障礙與側翼動線**：
  - 場內對稱配置 4 根工業緩衝柱（`(±5.5, ±3.8)`），將戰場自然切分為中央推進線與北側 `(0, -6.0)`、南側 `(0, +6.0)` 兩條側翼搶閥動線。
- **炸彈推車造型與回饋**：
  - 鋼鐵軌道底盤、隨 `cart_vel` 轉動的車輪、帶階段發光強度的重型彈頭圓柱，以及貼地推進光環與階段二／三衝擊波警示環。

## 5. 連線權威與 20 Hz 狀態同步

- **房主權威模擬（`multiplayer.is_server()`）**：
  - 所有玩家座標／硬直、推車位置／速度／火箭推進計時、衝擊波預警與引爆、蒸氣閥狀態及勝負結果均由房主統一計算。
- **輸入與快照 RPC**：
  - 客機上行：`move_dir: Vector2` 與 `action_pressed: bool`（沿用輕量輸入 RPC 模式）。
  - 房主下行：約 `20 Hz`（`0.05s`）廣播精簡快照，包含 `cart_x`、`cart_vel`、`cart_owner`、`surge_team`、`surge_timer`、`pulse_state`／`pulse_timer`、`valve_states`（南／北）、`phase`、`time_left`、`overtime` 與各玩家 `{pos, yaw, stun, ram_cd}`。

## 6. `lobby-bots` AI 控制器設計（`ai_controller.gd`）

每個機器人依局勢動態切換 3 種微角色，讓 2v2 至 4v4 混編機器人時能打出場內分工與反制：

1. **閥門游擊手（Valve Flanker）**：場上有啟動中的蒸氣閥且沒有更近的隊友前往時，指派 1 名機器人全速衝往側翼拍閥（但若推車距離自家閘門 `< 3.0m`，優先回防推車）。
2. **推車／助推手（Cart Pusher / Rammer）**：切入推車己方後側的推進光環內朝敵門推車，周圍無敵人時使用 `Space` 發動 Power Ram 助推；在階段二／三炸彈衝擊波預警的最後 `0.45s` 主動退至 `> 3.4m` 閃避。
3. **清場攔截手（Brawler / Blocker）**：偵測到敵人正在光環內頂車或搶先跑向亮燈閥門時，主動貼近並按 `Space` 發動工業推搡將其震開軌道。

## 7. 模組檔案結構與效能紅線

```text
mods/bomb-cart/
├── mod.json                 # id: "bomb-cart", requires: ["mpm-core", "team-party"]
├── main.gd                  # _mod_init / _mod_ready、註冊 max_teams: 2 admission 與場景替換
├── config.gd                # 平衡常數、顏色、階段時間、推進力與場地幾何輔助函式
├── official_minigame.gd     # 對接原版 Minigame 訊號介面
├── bomb_cart_game.gd        # 伺服器權威主邏輯、推車物理、蒸氣閥、脈衝與結算
├── arena_meshes.gd          # 軌道廠房、防爆閘門、緩衝柱、蒸氣閥與炸彈推車網格建構
├── ai_controller.gd         # lobby-bots 三角色協作與閃避 AI
├── fx_pool.gd               # 基於 mpm-core.create_fx_pool() 的火花／蒸氣／脈衝／爆門特效池
├── hud_ui.gd                # 頂部拉鋸進度條（紅 [===💣===] 藍）、階段警報與倒數計時
├── team_support.gd          # 複製自 mods/_shared/team-support/team_support.gd
├── self_test.gd             # --self-test 無頭邏輯與邊界驗證
└── README.md                # 模組說明文件
```

### 效能與契約紅線（對齊[自研模組開發規範](mod-development.md)）
- **零執行期配置**：所有火花、蒸氣噴流、脈衝衝擊波與爆門爆炸特效均透過 `mpm-core.create_fx_pool()` 預建，並於 3 秒準備期在相機視錐內以極小縮放預熱著色器。
- **熱路徑禁令**：`_process` / `_physics_process` 禁止呼叫 `get_property_list()`、禁止新建 `Mesh` / `StandardMaterial3D` 或 `queue_free()`。
- **無頭與 Lint 規範**：通過 `node scripts/mod-lint.mjs`、不可對 `call()` / `get()` / `get_meta()` 使用無型別 `:=`。
